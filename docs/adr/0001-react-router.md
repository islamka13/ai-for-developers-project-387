# Клиентский роутинг на react-router с маршрутами /, /booking, /admin

Приложению нужны три страницы уже на первом этапе: главная (`/`), страница записи (`/booking`), страница владельца (`/admin`) — последние две пока заглушки. Решили поставить react-router сразу, а не вводить маршрутизацию позже: ссылки на `/booking` и `/admin` попадают в разметку и тесты уже на главной странице, и переделывать их с якорей на роутер дороже, чем добавить роутер на пустом проекте. Альтернативы: обойтись без роутера (отклонено — три страницы уже на горизонте) и TanStack Router (отклонён — react-router стандартнее для пары Vite + React, агенты знают его лучше).
